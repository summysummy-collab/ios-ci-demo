安装到 iPhone

推荐Safari 直装（OTA）

不用连电脑，装完就能用；覆盖安装不丢自选股。

  1. 用 iPhone 的 Safari 打开本页（微信里点右上角「…」→ 在 Safari 中打开）。
  2. 点对应版本的「在 iPhone 上安装」，弹窗点「安装」。
  3. 回桌面等图标出现（几秒到半分钟，装的是 1 MB 不到的包）；找不到就下拉搜索「大单」。
备选电脑 + Apple Configurator / Xcode

OTA 死活装不上，或者就想用数据线装时走这条。

  1. 点「下载 .ipa（电脑用）」，或用私有仓库 Release ci-signed 里的完整版。
  2. 手机连电脑，打开 Apple Configurator → 添加 → App → 选 ipa。
  3. 或者 Xcode → Window → Devices and Simulators → 把 ipa 拖到设备上。

乐奇版和标准版装的是同一个 App。标准版（原版）里没有「设置 → 眼镜副屏」这一项， 眼镜端也就连不上——想用副屏必须先装乐奇版。

眼镜端怎么接上

乐奇版扫码交接自选股 + 局域网行情桥

眼镜不给第三方 App 开网络服务，所以反过来：手机当服务端，眼镜当客户端。

  1. 手机装好乐奇版，打开 App → 设置 → 眼镜副屏 → 生成配对二维码（一次性载荷，只含代码和名称）。
  2. 眼镜端进 AIUI 智能体「行情副屏」→ 扫码导入，自选股就过去了，不用一个个敲。
  3. 同一个设置页打开局域网行情桥：手机在 8788 端口起 HTTP + SSE 服务，眼镜订阅。
  4. 镜腿前滑 / 后滑切上一只 / 下一只；350 ms 内的连滑会合并成一次，不会一次跳三只。

顶栏角标 桥 = 走手机推的数据；直连 = 手机桥不通，眼镜自己拉公开行情源兜底。 看到「直连」说明手机那侧的开关没开、或者两台设备不在同一个 Wi-Fi。

智能体导入 .aix

智能体不在 ipa 里，它得单独装到眼镜上。

  1. 装上 aix-cli：npm i -g @yodaos-pkg/aix-cli。
  2. 眼镜连上电脑，执行 aix install ./aiui-agent-rokid-*.aix。
  3. 用 aix launch-page ./aiui-agent-rokid-*.aix pages/quotes/index 拉起行情页（务必带页面路径）。

校验与排错

  1. 「无法安装此应用」：手机 UDID 不在描述文件里，或描述文件过期了。换设备必须先加 UDID 重签。
  2. 点安装毫无反应：不在 Safari（微信/QQ/Chrome 都会静默失败），或者页面是用 http 打开的。复制链接到 Safari 重开。
  3. 装完桌面没有图标：桌面下拉搜「大单」；还是找不到就说明安装中途被取消了，重装一次。
  4. 分不清装的哪个版本：设置里有没有「眼镜副屏」——有就是乐奇版。
  5. 副屏一直显示「直连」：手机端行情桥没起来。确认开关打开、两台设备同一个 Wi-Fi、首次允许「本地网络」权限；8788 被占就在设置里换端口。
  6. 副屏没图 / 一直是横线：先确认这只股在自选里、当日有成交。收盘后没有分时增量，副图大单柱自然是空的。
  7. 切股没反应：滑动要在镜腿外侧的触控区，轻扫而不是长按；页面还在拉数据时滑动会被丢掉。
  8. 校验包是否被截断：shasum -a 256 结果要和页面上一致，不一致就重下。
